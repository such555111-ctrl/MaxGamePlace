# MaxGamePlace — Telegram Mini App магазина дисков и аксессуаров для PS4/PS5

Витрина магазина **MaxGamePlace** в виде Telegram-бота с мини-приложением (Telegram WebApp):
каталог, избранное, корзина, промокоды, оформление заказа, профиль с историей заказов
и админ-панель. Онлайн-оплата не подключена — заказ уходит менеджеру (@karammax),
дальше доставка или личная встреча в Москве.

## Состав репозитория

```
main.py           — Flask-сервер: мини-апп, Telegram-бот (webhook) и API админ-панели
index.html        — интерфейс мини-приложения (hero, каталог, корзина, заказ)
admin.html        — админ-панель (товары, заказы, вопросы, промокоды)
products.json     — каталог (админка читает и пишет в этот файл)
orders.json       — заказы (создаётся автоматически)
uploads/          — фото товаров, загруженные из админки
mgp-logo.svg, mgp-avatar.png, mgp-banner.png — логотип, аватарка бота, обложка (лежат в корне, не нужны для работы сервера)
requirements.txt, Procfile, render.yaml — запуск на Render
```

Цвета и шрифты — в `:root` в начале `<style>` в `index.html` и `admin.html`.

## Запуск

1. Создайте бота в [@BotFather](https://t.me/BotFather), сохраните токен, аватарку — `mgp-avatar.png`.
2. Загрузите файлы в GitHub и разверните на Render (**New → Web Service**):
   - Build: `pip install -r requirements.txt`
   - Start: `gunicorn main:app --bind 0.0.0.0:$PORT`
3. Переменные окружения: `BOT_TOKEN`, `ADMIN_PASSWORD`, `ADMIN_CHAT_ID` (ваш Telegram ID, можно несколько через запятую),
   `SHOP_CONTACT` (по умолчанию `karammax`), `WEBHOOK_URL` (необязательно на Render).
4. `/start` → «🎮 Открыть MaxGamePlace». Заказы получают номера вида `MGP-12`.

## Админ-панель

`https://ваш-адрес.onrender.com/admin` — товары (категории, цена, старая цена, бейдж, платформы/варианты, описание, фото),
заказы со статусами и сообщениями клиенту, вопросы покупателей, промокоды.

`products.json` содержит **примерный** стартовый каталог (названия — из вашего канала, **цены примерные**):
замените их реальными и добавьте фото через `/admin`.

## Постоянное хранилище

На бесплатном плане Render диск не сохраняется между рестартами — для `products.json`, `orders.json` и `uploads/`
подключите платный Persistent Disk (блок `disk:` в `render.yaml`).
